What the Unified MCP Dashboard does, and answers to common questions.

About this dashboard

The Unified MCP Dashboard brings observability, infrastructure, services, capacity forecasting, and topology data from your connected monitoring sources into a single view, instead of switching between each tool's own console.

Frequently asked questions

How often does data refresh?

Each page fetches its data once when you first open that tab in a session. Use a page's own refresh control (where available) to pull the latest data on demand.

Why is a section showing "Soon" in the sidebar?

That section is still under active development and isn't wired up yet. It'll become clickable as soon as it ships.

How do I add a new monitoring source?

Source management lives under Settings → MCP Servers, where you can register a new server, map its data fields, and configure how its issues are categorized.

Who can see what?

User Management lets you scope which sources' data each account can see. It's visibility bookkeeping only — it isn't a login or access-control system.

Something looks wrong or out of date — what do I do?

Try that page's refresh control first. If the issue persists, check the relevant source's connection status under Settings.
